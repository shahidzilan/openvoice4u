# Publication review — 2026-10-11

## Decision

The source can be shared for development as an explicitly experimental preview. This review does **not** approve a stable or security-cleared installer release. Use only the clean exported source archive, never the installed portable directory.

## Verified

- Backend tests and dependency consistency checks pass. Frontend compilation, native Windows startup with existing profiles, and navigation/layout checks passed during the redesign.
- The source export uses an allowlist, includes MIT licensing, and excludes installed runtimes, model weights, recordings, profiles and private development scripts. Archive contents and hashes are checked separately.
- npm audit returned zero known advisories for the locked JavaScript dependencies at review time.
- OSV was queried for 569 Python and Rust package/version pairs. Findings below remain unresolved; a database match is not proof that the affected code is reachable in this application.
- Both Rust findings are absent from `cargo tree --target x86_64-pc-windows-msvc`. They remain in the cross-platform lockfile.
- Runtime packaging now refuses a nonempty output directory, preventing stale dependencies or personal files from being merged into a release. Audio/history ignore rules were extended.

The installed `qwen-tts==0.1.1` package explicitly requires `transformers==4.57.3` and `accelerate==1.12.0`. Simply changing those lockfile lines creates a dependency conflict. The review therefore does not silently replace the working speech engine or claim these advisories are fixed. Advisory databases evolve; rerun scans for each release.

## Remaining release gates

1. Resolve or explicitly assess the runtime dependency findings with upstream-compatible changes and real audio regression tests.
2. Run the GitHub installer workflow and test installation, model downloads, reference upload, generation, export, cancellation and uninstall on a clean Windows machine. A local executable build is not this test.
3. Complete the binary dependency notice and corresponding-source review. In particular, FFmpeg's obligations depend on the exact libraries bundled by PyAV; see [FFmpeg's distribution guidance](https://ffmpeg.org/legal.html). The source-only ZIP does not contain those DLLs or model weights.
4. Complete a successful real 4,000-word job. The recorded stress test failed at segment 8 of 120; see [validation](validation.md). Do not advertise full long-form reliability or guaranteed professional audio quality.

## Other known limits found in review

- The model setup action verifies the original download but skips CPU cache conversion when the destination already exists. An existing corrupt CPU cache is not automatically repaired. Close the app and rename that model-cache directory before rerunning setup; do not delete voice data.
- Model readiness in the UI uses manifest existence, not a full integrity scan on every launch. Do not load model directories received from untrusted sources.
- WAV and MP3 publication uses hard links for no-overwrite behavior. Use NTFS destinations; export to some removable filesystems can fail.
- This was a source/build review and automated advisory scan, not a penetration test or legal certification.
