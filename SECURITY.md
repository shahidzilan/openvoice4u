# Security

Keep voice recordings, transcripts, model weights, and generation history out of issues and pull requests. Reproduce problems with synthetic audio when possible.

For vulnerabilities, use the repository's **Security → Report a vulnerability** page if private reporting is enabled. If it is unavailable, open an issue requesting a private contact without including exploit details or personal data.

Maintainers should enable private vulnerability reporting in repository settings. There is no promised response time or supported-version window yet; this is an early preview.

## Current release status

The preview has unresolved dependency advisories. Read [the publication review](docs/release-review.md) before building or distributing a binary. Only use official model downloads and trusted local model directories. Do not describe this release as security-cleared.
